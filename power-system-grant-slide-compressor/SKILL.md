# 电力系统基金 PPT 短语凝练

## 适用范围与触发条件

用于将研究内容、关键技术、阶段输出、内容间传递关系和创新点凝练为 PPT 标签或图内短语。用户提出不超过若干字、每项若干短语、格式相近或适合放图时触发。

不负责从短语反向创造研究内容，也不把方法、产出和科学问题混为一类。

## 共通约束

1. 依据实际稿件、代码、数据和结果判断，不由题目反推未提供的工作。
2. 先检查请求前提、短语类别和材料完整性，再开始压缩。
3. 区分事实、作者推断、研究设想和预期结果。
4. 不虚构文献、实验、数据、代码能力、修改结果或文件状态。
5. 用户要求先讨论时，不修改文件，不声称已完成修改。

## 所需输入

必需输入为原始正文和字数上限。可选输入包括每组短语数量、短语类别、受众、版式位置及是否需要突出特色。

## 前提检查

1. 先确认需要凝练的是研究问题、技术方法、阶段输出、传递对象还是预期成果。
2. 若用户要求先讨论，只给候选组和取舍理由，不修改 PPT 或文件。
3. 只从实际正文提取，不根据标题补充未出现的技术。
4. 发现正文层级混乱时先提示，不用短语掩盖结构问题。

## 执行步骤

1. 从每项内容提取对象、动作、方法和输出。
2. 按用户指定类别筛选，删除属于其他层级的词组。
3. 优先保留最能区分各研究内容的术语，避免三组重复使用同一上位词。
4. 将同组短语统一为名词结构或动宾结构，保持字数和语法平行。
5. 删除无信息量修饰词，如新型、先进、智能化和高效，除非其构成方法名称。
6. 逐条计数。汉字、英文字母和数字均计入字符数，标点不进入短语。
7. 给出推荐组合；存在不同强调方向时，可补充方法版和成果版。

## 输出格式

按研究内容或图中模块分组列出短语。默认每组提供三至八个，并保证每个短语不超过字数上限。用户要求时附字符数和取舍说明。

## 核查标准

1. 每个短语均能在原文中找到直接依据。
2. 每个短语满足字符上限，没有用生造缩写规避限制。
3. 同组短语处于同一语义层级，组间具有区分度。
4. 关键对象没有因压缩而发生歧义。
5. 不虚构技术、模型、结果、指标或内容间传递关系。
6. 遵守用户关于禁用词、标点和中英文混排的要求。

## 注意事项

短语越短，越应优先保留研究对象或关键关系。若八字以内无法同时保留对象与动作，应依据图中上下文省略已经由标题表达的对象。

## 请求示例

从三个研究内容中分别选出三个最有特色的技术短语，每个不超过八个字，用于技术路线图。
