# 电力系统基金文本保真润色

## 适用范围与触发条件

用于国家自然科学基金及类似申请书的局部或全文语言润色，包括立项依据、研究内容、科学问题、技术路线和意义表述。用户强调只改语言、保持原意、不讨论专业概念或不改变研究方案时优先触发。

不负责重新设计研究对象、补造理论、核验全部文献或替用户宣称实验已经完成。

## 共通约束

1. 依据实际稿件、代码、数据和结果判断，不由题目反推未提供的工作。
2. 先检查请求前提和材料完整性，再决定诊断、讨论或改写。
3. 区分事实、作者推断、研究设想和预期结果。
4. 不虚构文献、实验、数据、代码能力、修改结果或文件状态。
5. 用户要求先讨论时，不修改文件，不声称已完成修改。

## 所需输入

必需输入为待润色原文。可选输入包括章节功能、项目类型、字数、禁用词、术语表、文献编号和用户希望保留的句式。

## 前提检查

1. 判断用户要诊断、讨论、直接改写还是修改文件。
2. 用户要求先讨论时，不修改文件，只给问题定位和候选表达。
3. 检查原文是否缺少完成句意所必需的信息。缺失时标注，不自行补造。
4. 识别事实、推断、研究设想和预期结果，避免在润色中改变证据强度。

## 执行步骤

1. 标注每段的逻辑功能，如背景、现象、缺口、问题、方法、输出和意义。
2. 检查段内是否只有一个中心，句间是否形成递进、因果、转折或承接。
3. 锁定不得改变的研究对象、系统边界、时间尺度、方法名称、数据和引文。
4. 删除重复主语、空泛评价、同义堆叠和无指向的代词。
5. 调整长句层级，使条件、动作、对象和结果对应清楚。
6. 对可能改变专业含义或事实边界的句子单独标注，不静默改写。
7. 按用户指定的字数、标点和格式约束完成终稿。

## 输出格式

默认依次输出：核心判断、可直接替换稿、关键改动说明、待核实表述。用户只要成稿时，仅输出替换稿，并用不超过三点说明关键调整。

## 核查标准

1. 研究对象、变量关系、时间尺度和章节功能未被改变。
2. 文献编号、数据和已有结果未被新增、删改或夸大。
3. 每段首句定向，段中展开，段末承接下一层问题。
4. 科学问题不用方法名替代，预期结果不写成既成事实。
5. 术语前后一致，语气正式，避免宣传性和绝对化表达。
6. 完整遵守用户的字数、禁用词和标点要求。

## 注意事项

发现专业概念疑点时，用审校意见提示，不擅自改变物理内涵。需要事实核验时转用证据核查 Skill。需要重构研究内容时转用链条审校 Skill。
